## Last session

2026-10-03 (late): **media app state is finally durable, and Sonarr
and Radarr actually search through Jackett.**

- **Jackett had never worked** (`fe439a5`, `8965ef8`): Sonarr v4 and
  Radarr refuse Jackett's `/all` aggregate, the configurators passed
  no categories (so no search was ever built), and Jackett itself had
  zero indexers enabled. Now `jackett-config` carries an `indexers`
  list (`thepiratebay knaben`) that a Jackett configurator sidecar
  enables via its admin API and that sonarr/radarr read through
  `configMapKeyRef`, one Torznab entry per id. 1337x/eztv are behind
  Cloudflare and would need FlareSolverr; the other public trackers
  probed were dead or redirecting (see exploration-log).
- **The rollout wiped Sonarr's series list**, which exposed bug
  `vu9n`: sonarr/radarr/jellyfin/transmission `/config` had been
  `emptyDir` since the Longhorn migration, against ADR-0011. Fixed in
  `63c8745` (`<app>-config` PVCs on the default class, `fsGroup`
  1000, sonarr/radarr seed `config.xml` only on a fresh volume) and
  `4a923d4` (`strategy: Recreate` — the first restart deadlocked on
  Multi-Attach). ADR-0011 has a dated adoption note.
- sonarr/radarr PVCs were **seeded from the docker host's DBs** before
  the deployments rolled (sqlite `.backup` of the stopped containers,
  stale download-client/indexer rows dropped, copied in via a uid-1000
  helper pod). 29 series / 246 files and 9 movies came back; posters
  regenerated by a `RefreshSeries`. Restart across nodes verified.

- **Broken windows closed** (`7aabe29`, `ce3667c`): the Jackett API
  key is rotated and sealed (`phey`), and sonarr/radarr configurators
  now PUT their `Jackett (<id>)` entries back on every start so a
  rotated key reaches the persisted DBs. jellyfin and jackett run as
  1000 under PSS restricted (`90qw`); `media` has no PSS warnings on
  a server dry-run. Jellyfin had to move to the **upstream image**
  (`jellyfin/jellyfin`) — linuxserver's has no non-root branch — with
  env pinning lsio's `/config` layout so the PVC read as-is. A
  parallel commit (`6ca76f4`) added nyaasi + iptorrents (cookie-auth
  sealed secret) to the indexer list.

## Loose threads

  admin + libraries); the docker host's Jellyfin config
  (`config/plex`, TV at `/data/tvshows`) was *not* imported — owner

  the next revision**: a crash-looping pod from commit N blocks
  commit N+1's fix until the sync times out. `kubectl apply` of the
  committed manifest unblocks it (ArgoCD then sees Synced).

  now *behind* the cluster's (do not re-import).
